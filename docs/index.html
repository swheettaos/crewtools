Crew Tools

Host tools for Moon Sweepers crew games: what each crew-mate may do, where and how much, cheat catching, and the host chores. Only the host installs it.

What it does

Everything from one window in the pause menu: CREW TOOLS.

Permissions

Per player

Build, Demolish, Sell, Shop, Capsules: each on or off, with defaults for new players and a reset.

Protected bases

Look, don't touch

Near a protected base crew-mates can look and drive, but not build, demolish, sell, shop or handle capsules. Passes per player.

Spending cap

No draining the money

At most $X per crew-mate in any 30 minutes, priced before the purchase goes through. Trusted players have no cap.

Anti-cheat

Money and cheat watch

Building money must match what was really built; speed, flying, reach, deposits and teleports are watched. Ban, kick or ask you.

Host chores

The rest

A welcome in crew chat, your server name, cleanup of loose capsules, and everything a banned player built removed and refunded.

Updates

Updates itself

It names its GitHub releases (UpdateFeed()), so a mod that updates plugins can install new versions, in place while the game runs when it runs hot.

Install

You need BepInEx 6 (IL2CPP), as the game's other mods use.

  1. Download the zipFrom the latest release.
  2. Unzip it into the game folder, with the game closedYou get BepInEx/plugins/CrewTools/CrewTools.dll. Remove a separate CrewPermissions.dll if you have one: Crew Tools includes it.
  3. Start the gameThe log says "Crew Tools x.y.z loaded: 30 game hooks in place". Open the pause menu on the Moon: CREW TOOLS.

How a crew-mate's action is judged

Every building, shop or capsule message a crew-mate's game sends goes through the same checks on your side.

flowchart LR
  msg["A crew-mate's message
(build, demolish, sell, shop, capsule)"] --> sw{"Their switch
for it on?"}
  sw -- "no" --> no["Refused quietly
(a sale's capsule given back)"]
  sw -- "yes" --> zone{"Inside a protected base
without a pass?"}
  zone -- "yes" --> no
  zone -- "no" --> cap{"Over their
30-minute cap?"}
  cap -- "yes" --> no
  cap -- "no" --> ok["Allowed"]
  ok --> money{"Its money matches
what was built?"}
  money -- "yes" --> paid["Paid"]
  money -- "no" --> caught["Not paid; flagged,
or a catch: ban / kick / ask you"]
